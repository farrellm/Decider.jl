Decider.Decider — Module
Decider

Julia front end for decision models: ask a typed question about some state and get back probabilities over your own option type (an @enum or Symbols), or the most likely value. Backends: TypeSafe, OpenRouter, and OpenAIDecisions.

Decider.AbstractBackend — Type
AbstractBackend

A decision-model provider. To add one that speaks an existing wire format, define a struct with fields model, retries, and transport, and the methods codec, endpoint_url, and headers; override max_questions, supports_images, and request_extras when the defaults do not fit.

Decider.AbstractQuestion — Type
AbstractQuestion{T}

A question for a decision model. T is the type of the answer's values: the option type for Choice, the level type for Score, and Bool for YesNo.

source
Decider.Answer — Type
Answer{T}

A decision model's answer to one question.

  • value::T: the most likely option (for YesNo, p ≥ 0.5).
  • probabilities::OrderedDict{T,Float64}: the distribution, in declaration order (for YesNo, true then false).
  • confidence::Union{Nothing,Float64}: the model's confidence, when reported.
  • score::Union{Nothing,Float64}: for Score, the expected 0-based ordinal.
  • model, usage: from the response, when reported.
  • raw: the parsed JSON answer for this question.

Decider.Choice — Type
Choice(E::Type{<:Enum}, instructions; descriptions=nothing)
Choice([:a, :b, :c], instructions; descriptions=nothing)
Choice([:a => "description", :b => "description", :c], instructions)

Ask the model to pick one of several options. The answer type T is E for an enum and Symbol otherwise; options are kept in declaration order.

instructions is a String or any JSON-serializable value. Option descriptions come from the pairs, the descriptions keyword (a Dict or pairs keyed by option), or Decider.describe. Options are sent as string(x); there must be 2–255 of them, with distinct non-empty names.

Decider.Image — Type
Image(bytes::Vector{UInt8}, mime)
Image(path::AbstractString)

An image to include in the state, as an element of a Vector state: ["What is in this picture?", Image("cat.png")]. Only backends that accept images (currently OpenAIDecisions) can send them; others throw ArgumentError before making a request. The path form infers the MIME type from the extension (png, jpg/jpeg, gif, webp).

Decider.OpenRouter — Type
OpenRouter(; api_key=ENV["OPENROUTER_API_KEY"], model="typesafe/jev-1.13",
             endpoint=:decisions, provider=nothing, session_id=nothing, user=nothing,
             base_url="https://openrouter.ai", timeout=60, retries=3, transport=nothing)

Any OpenRouter decision model, over the System One wire format. endpoint=:decisions uses /api/alpha/decisions, which routes to every decision model and accepts the provider (routing preferences, any JSON-serializable value), session_id, and user fields; endpoint=:systemone uses the stable /api/v1/systemone.

Images in the state are not supported.

Decider.ProbabilitiesUnavailable — Type
ProbabilitiesUnavailable(question)

The model returned only its chosen value, without probabilities. Pass allow_point_mass = true to get a one-hot distribution instead, or use decide.

Decider.Score — Type
Score(levels, instructions; descriptions=nothing)

Ask the model to rate on an ordered scale. levels is an Enum type (declaration order is the ordinal) or a Vector of Symbols and/or Symbol => description pairs, with 2–10 levels. Descriptions work as for Choice; a level without one is described by its name.

The Answer carries .score, the expected ordinal (0-based), and decide returns the most likely level. When you want a single level that respects the whole distribution, levels[round(Int, a.score) + 1] is often the better choice.

Decider.TypeSafe — Type
TypeSafe(; api_key=ENV["TYPESAFE_API_KEY"], model="jev-latest",
           base_url="https://api.typesafe.ai", timeout=60, retries=3, transport=nothing)

The TypeSafe System One API (POST /v1/systemone). Text and JSON state only. The API key is read when a request is made, not at construction.

transport replaces the HTTP call; it is a function (method, url, headers, body) -> (status, headers, body).

Decider.YesNo — Type
YesNo(instructions; yes=nothing, no=nothing)

Ask a yes/no question. yes and no optionally describe what counts as each answer. probabilities returns true => p, false => 1 - p, and decide returns p ≥ threshold (default 0.5).

Decider.ask — Method
ask(backend, question, state; allow_point_mass=false) -> Answer{T}
ask(backend, (name = question, ...), state; allow_point_mass=false) -> NamedTuple

Ask a decision model question about state and return the full Answer. A NamedTuple of questions is sent in one request (split as the backend requires) and answered with a NamedTuple of Answers under the same names.

state is a string, any JSON-serializable value, or a Vector that may contain Images when the backend supports them.

Throws Decider.ProbabilitiesUnavailable if the model returned only its chosen value, unless allow_point_mass = true, which substitutes a one-hot distribution.
